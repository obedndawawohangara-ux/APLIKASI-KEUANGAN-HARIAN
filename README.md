# APLIKASI-KEUANGAN-HARIAN
Laporan Capstone Project Batch 10
Judul Program:
Aplikasi Pencatatan Keuangan Harian
Deskripsi Program

Aplikasi Pencatatan Keuangan Harian merupakan aplikasi berbasis web yang dibuat menggunakan HTML, CSS, dan JavaScript. Program ini bertujuan untuk membantu pengguna mencatat transaksi keuangan harian berupa dana masuk dan dana keluar secara sederhana. Data transaksi disimpan menggunakan Local Storage, sehingga data tetap tersimpan meskipun browser ditutup dan dibuka kembali.
Fitur Program
	Input transaksi dana masuk dan dana keluar. 
	Format nominal otomatis dalam mata uang Rupiah. 
	Menampilkan total pemasukan, total pengeluaran, dan saldo secara otomatis. 
	Menampilkan daftar transaksi dalam bentuk tabel. 
	Edit dan hapus data transaksi. 
	Penyimpanan data menggunakan Local Storage. 
	Export data transaksi ke file keuangan.txt dalam format tabel. 
Teknologi yang Digunakan
	HTML 
	CSS 
	JavaScript 
Cara Menjalankan Program
1.	Buka file index.html menggunakan browser. 
2.	Masukkan jenis transaksi, jumlah, kategori, tanggal, dan deskripsi. 
3.	Klik tombol Simpan untuk menyimpan data. 
4.	Data akan ditampilkan pada tabel dan saldo akan diperbarui secara otomatis. 
5.	Klik tombol Export keuangan.txt untuk mengunduh data transaksi dalam bentuk file teks. 
Hasil Pengujian
Program telah diuji dan seluruh fitur utama dapat berjalan dengan baik, yaitu:
	Program dapat dijalankan tanpa error. 
	Data transaksi dapat disimpan dan ditampilkan pada tabel. 
	Fitur edit dan hapus data berfungsi dengan baik. 
	Total pemasukan, total pengeluaran, dan saldo dihitung secara otomatis. 
	Data tersimpan menggunakan Local Storage sehingga tetap tersedia saat aplikasi dibuka kembali. 
	File keuangan.txt berhasil dibuat melalui fitur Export. 
Kesimpulan
Aplikasi Pencatatan Keuangan Harian telah berhasil dibuat sesuai dengan tujuan Capstone Project. Program mampu membantu pengguna dalam mencatat transaksi keuangan harian, menghitung saldo secara otomatis, menyimpan data, serta mengekspor data ke dalam file teks. Seluruh fitur utama telah berfungsi dengan baik dan aplikasi siap digunakan.
